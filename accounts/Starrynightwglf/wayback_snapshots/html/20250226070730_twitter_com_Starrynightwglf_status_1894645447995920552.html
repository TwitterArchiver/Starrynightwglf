谷歌向开发者推出 Gemini Code Assist 编程助手个人版，每月提供高达 18 万次的代码补全配额相当于几乎免费。

对比 GitHub Copilot 免费版每月 2000 次代码补全，谷歌给的配额估计也用不完，即日起开发者就可以在 VSCode 或 JetBrains 中安装这个助手。
